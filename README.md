# Домашка

Telegram Mini App: https://t.me/domaaashka_bot
Frontend: GitHub Pages. Backend: Supabase Edge Function `domashka`, PostgreSQL private schema `domashka`.

## Организатору

- В разделе «Люди и ответы» добавляй и убирай участников из актива. Строчная отметка «a» видна только администратору.
- Для текстовой рассылки выбирай «Всем участникам» или «Только активу». Перед отправкой есть предпросмотр и подтверждение.
- Для голосового или кружка отправь запись в личный чат бота. Она сохранится как черновик. Затем открой админку → «Рассылка», проверь запись, выбери аудиторию и отправь.
- Кнопка «Подготовка в субботу» заполняет опрос «Будешь на домашке-подготовке в субботу, 21 ноября?» с вариантами «Буду / Не буду» для актива. Опрос отправляется прямо в личный чат бота выбранной аудитории после подтверждения. Ответы записываются в админке.
- Ответы на опросы именные и доступны только организатору. В опросе видно, кто ещё не ответил.

## Публикация обновления

Сначала выполнить additive migration.sql в исходном проекте. Затем обновить Edge Function файлами index.ts и app.js (проверка JWT шлюза остаётся прежней; API самостоятельно проверяет Telegram initData и webhook secret). Для опросов Telegram дополнительно выполнить telegram-polls.sql и обновить оба файла Edge Function: index.ts и app.js. После проверки сервера опубликовать index.html на GitHub Pages.

Токен бота и параметры сервера остаются в Supabase Vault. Не добавлять в публичный репозиторий ключи, выгрузки анкет и записи участников.

## Опросы в Telegram

Выбирай аудиторию «Только актив» или «Все участники». Кнопка отправки показывает вопрос, варианты и количество получателей перед подтверждением. Опросы неанонимные, с одним ответом и возможностью переголосовать. Каждый получает отдельный опрос в личном чате; общие именные результаты доступны только организатору в приложении. При первом создании бот автоматически включает webhook poll_answer.

В админке можно закрыть или удалить опрос. Удаление скрывает его в восстанавливаемой истории и запрашивает удаление сообщения у Telegram. Если Telegram не разрешает удалить старое сообщение, бот пробует закрыть опрос.
